# 45–60 Second Demo Script

**0–5 sec:** Show the deployed app. “I built an AI Movie Night Planner using Databricks.”

**5–15 sec:** Enter a natural-language movie request and show the recommendation/search experience.

**15–25 sec:** Show semantic search. “The query is converted into an embedding and matched against stored movie/review vectors using pgvector.”

**25–35 sec:** Show Databricks App/Lakebase. “Movie documents and watchlists are stored in Lakebase, with vector tables used for semantic retrieval.”

**35–45 sec:** Show MCP tooling. “I also exposed movie discovery, watchlist and vector-search capabilities through an MCP server so an agent can use them as tools.”

**45–60 sec:** Show architecture. “This project was a hands-on exploration of Databricks, data engineering, vector search and agent-ready AI workflows.”
